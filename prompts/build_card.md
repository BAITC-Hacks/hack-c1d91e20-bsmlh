Собери редактируемую карточку задачи только из исходного текста бизнеса и его ответов.
Поля: title, context, need, users, data, constraints, expected_result, success_criteria,
contact, interaction_format. Если факта нет — верни пустую строку. Для каждого заполненного
поля sources[field] должен содержать точную дословную цитату из исходного текста или ответов,
которая подтверждает поле. Не добавляй числа, сроки, названия, технологии, контакты или
предположения. Если точную цитату подобрать нельзя, оставь поле и его source пустыми.
Не подтверждай карточку и не публикуй её. Верни только JSON по схеме.
