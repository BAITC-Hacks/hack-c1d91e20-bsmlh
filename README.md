# AI SANA

AI SANA — MVP платформы, которая помогает бизнесу превратить сырую идею в понятную и готовую к работе задачу для студенческих команд.

Бизнес описывает задачу своими словами, система задаёт уточняющие вопросы, формирует редактируемую карточку и рассчитывает прозрачный рейтинг готовности от 0 до 100. После публикации студенческие команды могут найти задачу в каталоге, отправить предложение, а бизнес вручную выбирает или отклоняет команду.

## Основной сценарий

Business draft
→ clarification questions
→ editable task card
→ confirmation
→ readiness score
→ publication
→ catalog
→ student proposal
→ manual business decision

AI помогает структурировать информацию, но:
- не придумывает факты;
- не определяет рейтинг;
- не выбирает команду;
- финальное решение остаётся за человеком.

## Ключевая идея

Главная геймификация направлена на бизнес: чем качественнее описана задача, тем выше её readiness score и позиция в каталоге.

Рейтинг полностью детерминирован и рассчитывается кодом, а не LLM.

## Рейтинг готовности

Максимум: 100 баллов.

- Контекст и потребность — 20
- Данные и материалы — 20
- Ожидаемый результат — 15
- Критерии успеха — 15
- Ограничения — 10
- Пользователи — 10
- Связь с бизнесом — 10

Уровни:
- 0–39 — Черновик
- 40–69 — Рабочая
- 70–89 — Готовая
- 90–100 — Приоритетная

Пустые, расплывчатые, мусорные или неподтверждённые сведения не должны давать высокий балл.

## AI-функции

AI используется для:
1. Анализа полноты описания и генерации уточняющих вопросов.
2. Формирования редактируемой карточки задачи из текста и ответов пользователя.

Если `OPENAI_API_KEY` отсутствует или API недоступен, приложение использует локальный fallback и основной сценарий остаётся доступным.

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/BAITC-Hacks/hack-c1d91e20-bsmlh.git
cd hack-c1d91e20-bsmlh
```

### 2. Создать виртуальное окружение

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows:

```bash
py -m venv .venv
.venv\Scripts\activate
```

### 3. Установить зависимости

```bash
python -m pip install -r requirements.txt
```

## Переменные окружения

OpenAI API необязателен.

Для запуска с OpenAI:

```bash
cp .env.example .env
```

`.env`:

```env
OPENAI_API_KEY=your_key_here
```

`.env` не должен попадать в Git.

Без API-ключа приложение автоматически работает в fallback-режиме.

## Тесты

```bash
python -m pytest -q
```

На текущей версии проекта проходят 127 тестов.

Проверяются:
- формула рейтинга;
- расплывчатые и неподтверждённые ответы;
- backend integration flow;
- сохранение задачи;
- публикация;
- создание отклика;
- ручное изменение статуса отклика.

## Как проверить основной сценарий

Пример слабого описания:

```text
Хотим чат-бота для клиентов
```

Далее:
1. Открыть создание задачи.
2. Ввести слабое описание.
3. Ответить на уточняющие вопросы.
4. Проверить сформированную карточку.
5. Посмотреть readiness score и рекомендации.
6. Отредактировать и подтвердить карточку.
7. Опубликовать задачу.
8. Переключиться на студенческую команду.
9. Найти задачу в каталоге.
10. Отправить предложение.
11. Переключиться обратно на бизнес.
12. Вручную выбрать или отклонить предложение.

## Правила каталога

- Опубликованные задачи доступны всем командам.
- Основная сортировка — по readiness score по убыванию.
- Низкий рейтинг не скрывает задачу и не запрещает отклик.
