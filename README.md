# AI SANA

MVP platform for improving business tasks and publishing them for student teams.

## Main flow

Business draft
-> clarification questions
-> editable task card
-> readiness score
-> catalog
-> student proposal
-> manual business decision

## Stack

- Python 3.12
- Streamlit
- Pydantic
- OpenAI API
- JSON / SQLite
